# 横断幕デザイン＆実寸サイズ感シミュレーター

スポーツ応援やイベント向けの横断幕をブラウザ上でデザインし、**実際に人が持った時・フェンスに掲示した時の実寸サイズ感**を1cm単位のスケールで比較シミュレーションできるReactアプリケーションです。

## 公開ページ (GitHub Pages)

https://nonohp.github.io/banner-simulator/

## 主な機能

- **リアルタイムデザイン編集キャンバス**
  - 横断幕のサイズ指定（横幅 60〜600cm / 縦幅 30〜300cm、定番サイズプリセット対応）
  - 複数テキストレイヤーの追加・複製・削除・ドラッグ移動・縦書き/横書き切り替え
  - 日本語・欧文30種以上のWebフォント検索、ローカルフォント（`.ttf` / `.otf` / `.woff` / `.woff2`）やGoogle Fontsの動的追加
  - 背景カラー（単色・グラデーション・パターン模様・枠線・ハトメ表示）のカスタマイズ
  - ロゴ・イラスト画像レイヤーの追加と背景画像の読み込み
- **実寸サイズ感シミュレーション（人物比較）**
  - 身長（130〜195cm）・人数（1〜6人）・持ち方（胸の前／腰の位置／頭上／フェンス掲示）を切り替えて実寸比較
- **✨ AIスローガン提案・書き換え / 📷 画像OCR復元（Gemini API連携）**
  - 伝えたい思いやテイストに応じたスローガン案の自動提案
  - 横断幕の写真・スクリーンショットからの文字・配色・レイアウト自動読み取り＆編集可能な状態への復元
- **高画質PNGエクスポート**
  - 横断幕デザイン単体および人物比較図をPNG画像として保存可能

## セットアップ

### 必要環境

- Node.js 20以上推奨

### インストールと起動

```bash
npm install
npm run dev
```

### AI機能（スローガン提案・画像OCR）を使う場合

`.env.example` を `.env.local` にコピーして Gemini API キーを設定してください。

```bash
cp .env.example .env.local
```

```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```
